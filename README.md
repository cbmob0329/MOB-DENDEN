# MOB GUN CAT v0.5

スマホ / PCブラウザで動く、二丁拳銃3Dアクションのプレイアブル試作です。

## v0.5追加
- 二丁拳銃専用クロス・オートエイム：左右それぞれの銃口からロック対象の中心へ収束
- 敵ヒット判定を約25〜35%拡大してスマホ向けに補助
- 高速弾のすり抜け防止：フレーム間を線分判定するSwept Hit Testを追加
- ロック対象撃破後は近い敵へ自動切替

## v0.4追加
- オートエイム強化：近い敵を自動ロック、射撃中に自動旋回
- 回避アクション：方向入力＋DODGEで短距離無敵ステップ
- レベルアップ3択：EXPでレベルアップし、ランダム強化を1つ選択
- 敵4種類：CHASER / GUNNER / SHIELD / RUSHER
- ボス：5WAVEごとにVOLT BRUTE、専用HPバーと強化フェーズ
- 必殺技：SPECIALゲージMAXで360°二丁乱射

## 操作
### PC
- 移動：WASD / 矢印
- 射撃：Space長押し
- 回避：Shift
- 必殺：Q
- 会話送り：E / Enter

### スマホ
- 左：十字キー移動
- 右：⚡長押しで射撃
- D：回避
- SP：必殺

## 補足
- 現在の主人公はコード生成の仮3Dモデルです。
- Blenderで制作中のGLBモデルに差し替える前提の構造です。
- Three.jsはCDNから読み込むため、GitHub Pages等のネット接続環境で実行してください。
