# MOB CHILL LIFE

モブデンデンとモブピンクの、部屋づくりと共同生活の3D箱庭。正式な武器なしスプライト20ポーズ×2人を組み込んでいます。

## 遊ぶ

index.html、またはMOB_CHILL_LIFE.htmlをChrome / Edge / SafariなどWebGL対応ブラウザで開いてください。Three.jsと画像を同梱し、ネット接続は不要です。スマホのファイルプレビューではなくブラウザで開いてください。

- ドラッグで回転、ピンチ・ホイール・＋−で拡大縮小。↺でおすすめ視点。
- キャラか下の名前をタップして12種類の行動へお誘い。作業中は片付け後に次へ進みます。
- どら焼きを置くと1個だけテーブルへ。ふたりが好きなタイミングで取り、テーブルから離れて食べます。勝手に補充されません。
- 部屋づくりで3色・3配置を選択。ふたりの作業と退避が終わってから配置を変えます。
- Ⅱは停止・再開、1×は1/2/4倍速。音は任意ONの小さな合成音です。
- ···から記録・保存・初期化。記録と家具設定はこのブラウザ内だけに保存します。

## 行動

散歩、ソファ休憩、ベッド睡眠、どら焼き、読書、窓、掃除、水やり、ダンス、会話、ターンテーブルDJ、よろこぶ。

ベッドは端へ乗って中央まで移動し、寝具の平面に横になります。本は棚の1冊を取り、顔が棚に隠れないよう一歩下がって読み、戻して返却します。デンデンは「やんす／やんす～」、喜ぶと両手を頬に「ほぅ～！」。ピンクは「僕／であります」。

## 保存

家具色・配置・行動記録・未取得のどら焼きを保存。再読込時はふたりを安全な床へ戻します。手に取ったどら焼きは食べ終えた扱いで保存し、再読込で増殖しません。ゲーム内時刻の新システムはまだ実装していません。

## 構成

- game.js: 行動・予約・手の位置変換・保存・UI。
- room.js: 家具形状・当たり判定・接触点・3配置。
- assets/: 正式40PNG、実測アンカーmeta、埋込み画像辞書。
- vendor/: Three.js 0.160.1とMITライセンス。
- build.cjs: node build.cjsでMOB_CHILL_LIFE.htmlを再生成。遊ぶだけならNode不要。

HTML単体で遊ぶ場合は MOB_CHILL_LIFE.html を開いてください。ソースから遊ぶ場合はフォルダー内の index.html を開きます。

## 検証

Windows Edgeの実WebGLで正式40画像読込と実画面を確認。3配置×2人×12行動の72ケース、5seed各1時間の自律動作、どら焼き個数、保存復元、使用中の配置変更、停止・低fps・ピンチ、320/390/430pxとPCを検証。ブラウザJS例外0、外部通信0。食事中にテーブルが顔を隠す点を見つけ、取得後に一歩下がる動きへ修正しました。

実機iPhone/iPad Safariは未検証です。検証画像と結果は QA/ に入っています。
