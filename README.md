# MOB GUN CAT v0.7 MOBILE PAD FIX

スマホ操作の不具合修正版です。

## v0.7 修正
- スマホ / タブレットではバーチャルパッドを強制表示
- 画面幅1024px以下でもPADを表示し、横向きスマホでも消えないよう修正
- iOS / Androidの可視領域に合わせるため100dvh対応
- 左PADを見やすく強化
- Dボタンを DODGE に変更
- 回避距離を短い安全なステップに作り直し、障害物すり抜けを防止
- 回避ボタンのPointer Captureを廃止してタッチ不具合を回避
- バトル開始時の説明ダイアログを廃止し、開始直後からFIREで撃てるよう変更
- 長押し選択 / コンテキストメニュー / ダブルタップズーム抑止は継続

## スマホ操作
- 左バーチャルパッド: 360度移動
- FIRE: タップ / 長押しで二丁拳銃射撃
- DODGE: 入力方向へ短距離無敵回避
- SP: SPECIAL 100%で必殺技
