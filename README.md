# MOB CHILL LIFE — オーブンと焼きたての暮らし

モブデンデンとモブピンクの3D箱庭。正式56枚の武器なしドット絵を組み込み、あくび・背伸び・手振り・音楽ノリ、大の字の寝姿を追加しました。

## 遊び方

単体MOB_CHILL_LIFE.htmlをWebGL対応ブラウザで開きます。ネット接続不要。編集用入口はindex.html。node build.cjsで単体HTMLを再生成できます。

キャラや下の名前から行動へお誘い。部屋づくりで3色/3配置。ドラッグ回転、ピンチ/＋−で拡大、視点ボタンで切替。Ⅱは一時停止、1×は速度、…は記録・保存・初期化。音は任意ONです。

## オーブン

初回は小麦10、小豆10、所持どら焼き0。オーブン本体か下部の「オーブン」をタップし、小麦1個と小豆1個を入れると、実時間60秒でどら焼きが1個できます。

扉とトレーが動き、材料が炉内へ。焼成中は暖かい光と焼き色が変化し、完成後は湯気とランプが知らせます。「受け取る」で所持どら焼きが増え、「置く」で所持から1個をテーブルに出せます。ふたりが好きなときに食べます。空いているキャラは焼き加減を見守ります。

1回に1個。受取前に次の調理はできません。材料が足りないと開始できません。自動補充・販売はなく、初期化したときだけ初期数に戻ります。速度倍率や一時停止は焼成時間に影響しません。ブラウザを閉じても保存済みの完成時刻から判定します。端末時計を基準にします。

## 保存

既存の家具・行動記録を引き継ぎ、新しい材料在庫だけを一度追加。旧セーブでテーブル上にある食べ物も維持します。調理状態・材料・受取・配膳は操作時に保存。保存不可のときは材料を使う操作を戻してお知らせします。

V3本体の12行動に「焼き加減をみる」を追加。部屋のオーブンは3配置すべてで移動の障害物として扱い、安全な作業位置へ歩きます。

## 構成

room.jsは3D家具と経路用の占有領域、game.jsは行動/保存/UI、oven.jsは調理と演出、assetsは56画像とmeta、vendorはThree.jsとMITライセンスです。sprite-sheetsは素材確認用です。
