## 操作

- 上部の **家／カフェ** をタップ、またはその帯を左右にスワイプ。キャラの位置は変わりません。床のドラッグは従来どおりカメラ回転です。
- 家の **家具** で選択、方向ボタンで0.25ずつ移動、90°回転、収納／部屋に出す、配置を確定。オレンジ枠が現在、緑が提案位置、赤が配置不可です。キャンセルで破棄します。
- 調理は部屋の **オーブン・フライパン・鍋を直接タップ**。完成後は器具上の **料理アイコン＋完成！** をタップして回収します。所持品メニューから調理は開始しません。
- **モブイルカエル** をタップし、料理と数量を選んで預けます。所持品からその数だけ移り、着席した客へ看板娘が歩いて運びます。
- **モブニョロ** をタップするとカフェへの誘い、帰宅、傘の開閉ができます。デンデン、ピンク、ニョロは自律的にもカフェへ行きます。

## 料理と保存

どら焼き＝小麦1＋小豆1、卵焼き＝卵1、コーンスープ＝とうもろこし1＋牛乳1。各60秒（暫定既存値）。既存の材料・所持品・家具・行動履歴を維持し、保存キー `mob-chill-life-v2` も変更していません。
ブラウザや開くURLを変えると保存領域が変わる場合があります。これまでと同じ起動方法を使ってください。

カフェはテーブル1台／2席。空席がなければ待ってから帰宅し、在庫がなくても注文を捏造しません。食事開始時に消費を確定します。再読込では運搬中の未消費料理をカフェ在庫に戻し、席を解放し、カフェにいた住民は入口から再開します。完了した食事は戻しません。
