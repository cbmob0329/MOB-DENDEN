# MOB CHILL LIFE

モブデンデンとモブピンクが暮らす、小さな3Dの部屋。正式な武器なしドット絵56枚を組み込んだ、ネット接続不要の箱庭ゲームです。

## 起動と操作

`MOB_CHILL_LIFE.html` をWebGL対応ブラウザで開きます。編集用の入口は `index.html`、単一HTMLの再生成は `node build.cjs` です。ライブラリも同梱しています。

- キャラまたは名前をタップ：行動に誘う。
- 部屋をドラッグ：カメラ回転。ピンチ／ホイール／＋−：拡大縮小。視点ボタン：カメラ切替。
- 色・配置：3色と3つの基本配置。家具：個別の表示・収納・位置・90度回転。
- Ⅱ：一時停止。1×：1・2・4倍速。音：任意ON。…：記録・保存・初期化。

家具は重なり、部屋外、必要な通路をふさぐ配置には変更できません。使用中なら、キャラが作業を終え、降りてから反映します。TV・PC・小テーブルは最初は収納中です。PCの初期位置にはコンロがあるため、どちらかを移動または収納してください。

## 調理と配膳

|料理|材料|器具|時間|
|---|---|---|---|
|どら焼き|小麦1＋小豆1|オーブン|実時間60秒|
|卵焼き|卵1|フライパン|実時間60秒|
|スープ|とうもろこし1＋牛乳1|鍋|実時間60秒|

部屋に設置したオーブン・フライパン・鍋を直接タップし、その器具専用のパネルで材料を入れます。鍋とフライパンは別々にタップしてください。下の「所持品」は閲覧専用で、調理開始・受取はできません。残り秒数・煙・火・湯気で状態がわかります。完成後は同じ器具をもう一度タップして受け取り、「配膳」で料理を選ぶとテーブルに1皿置けます。ふたりは手に持ち、食べ進めます。料理のあるテーブル、調理中・受取前の器具は移動・収納できません。

配置編集中は「暮らし」に戻ってから器具をタップします。収納中の器具では調理できません。器具を動かしたら、移動先で再度タップしてください。小さい器具はピンチ／＋で拡大すると操作しやすくなります。

材料は各10個、料理は0個から開始。自動補充はなく、初期化時だけ戻ります。旧セーブには卵・とうもろこし・牛乳を一度だけ各10個追加します。卵焼きとスープの材料・時間は暫定設定で、`living.js` のレシピ定義から変更可能です。

調理は端末時計を基準とし、ゲーム速度・一時停止に影響されません。再読込やブラウザを閉じた後も保存した終了時刻で判定します。端末時計を変更すると調理にも影響します。

## 行動

各キャラ16種類：おさんぽ、ソファでひと休み、ベッドでおひるね、料理を食べる、本を読んで戻す、窓をながめる、おそうじ、植物に水やり、音楽とダンス、ふたりでお話、ターンテーブル、よろこぶ、焼き上がりを見る、TVを見る、PCをながめる、コンロを見る。

家具へ歩き、予約して順番に使用します。収納中の家具や料理・調理が必要な行動は、条件を満たすと選べます。寝姿には薄い立体感、食事には揺れと音符、食べ進めた料理の変化があります。ハートは食事や喜びの場面だけです。

## 保存と構成

部屋・家具・材料・調理・配膳・行動記録はブラウザ内に保存。旧セーブを引き継ぎます。保存できない場合は操作を巻き戻して通知します。ブラウザや起動URLを変えると保存先が別になる場合があります。

`room.js`：部屋・家具・経路判定。`game.js`：行動・UI・保存。`oven.js`：基本調理。`living.js`：家具編集・追加料理・演出。`assets`：正式画像とアンカー情報。`vendor`：Three.jsとMITライセンス。

Windows Edgeで実画面とタッチ操作を検証済み。実機iOS/Safariは未検証です。公開版のUI消失については対象URLが未確認のため、原因特定・公開修正済みとは扱っていません。commit・push・公開は実施していません。
