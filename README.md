# MOB CHILL LIFE — V8

起動：**MOB_CHILL_LIFE.html**。編集用：index.html。再生成：node build.cjs。

## 今回の変更

- ニョロを前版の85%に縮小。原本PNGは変更せず、体と傘を同じ表示倍率で縮小し、足元アンカーを保持。
- カフェは小テーブル3台と椅子3脚。1卓につき1人、3人が同時に食事できます。棚とカウンターはそのまま。
- 配膳は「接近→停止→そっと下ろす→卓上に置く→手を戻す」。トレーと料理を一緒に動かし、卓上配置が済んでから食事を始めます。
- スマホの動向カードと自動会話は **住民・履歴** に折り畳みました。必要なときだけ開けます。料理の完成吹き出しはそのままタップできます。
- イルカエルの料理預入は、料理カードで **＋／− → 個数を確認 → あずける**。複数料理をまとめて渡せます。確認前なら戻るだけで取り消せます。
- イルカエルに状況別の39台詞。選択順を保存して重複を抑えます。ニョロの香りを褒める台詞は「ここは落ち着くニョロ～」に変更。

## 操作

上の **家／カフェ** をタップ、またはその帯を左右スワイプ。床ドラッグはカメラ回転、＋／−はズームです。画面を切り替えても住民は移動しません。住民は家のドアから自分で歩きます。

家の **家具** は従来どおり選択・方向ボタン・回転・収納・確定・キャンセル。カフェの **家具** はテーブルと椅子を1組ずつ収納／再配置します。予約・着席・配膳中の席は収納できません。カフェの3卓は動線を確保した定位置です。

料理はオーブン／フライパン／鍋を直接タップして調理。完成吹き出しで回収し、**住民・履歴 → モブイルカエル** で預けます。各料理60秒、材料は従来のままです。

保存キー mob-chill-life-v2 は変更しません。既存の所持品・材料・家具を保持。旧2席データは3席へ移行し、運搬・着地待ちの未消費料理は在庫へ一度だけ戻します。消費済みは戻しません。再読込時のカフェ住民は入口から再開します。
