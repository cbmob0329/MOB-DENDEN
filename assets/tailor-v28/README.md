# 衣装屋の店主・ゲーム用画像

参照原本は追加ZIPの reference_original.jpeg（このフォルダの reference.jpeg）。原本とZIPは保持。生成は imagegen スキルの **built-in image_gen モード**を使用し、採用PNGをプロジェクト内へコピーしました。Blenderの完成キャラクターモデルではありません。

## 採用ファイル

- turnaround.png：2×2、正面の針持ち／正面の空手／横／背面。確認用4姿勢。
- walk.png：4×4、正面・背面・画面右・画面左の各4歩行フレーム。針は携行しません。
- life.png：4×4。待機2、挨拶2、仕立て4、針持ち2、取り外し／収納用2、着席2、睡眠2。読書・食事は現段階で着席フレームを共用します。
- dimensions.json：ZIPに同梱された建物・家具寸法。pack-tailor-v28.cjsが画像とともに assets/tailor-v28.js へ梱包します。

## 使用したプロンプトの仕様と修正内容

共通：参照人物の外観を保った、ゲーム用の透過背景カートゥーンスプライト。黒く口のない顔、赤い大きな目、金縁の丸眼鏡、左右非対称に曲がった幅広の長いウサギ耳。白・赤・黒と金のボタン。正面左の大きな赤金のリボンと黒いX、白赤の重なった衣服、金の縁、肩のR飾り、黒い手袋、短い脚と赤白金の靴。口・鼻・尻尾を追加しない。針は大きな銀の縫い針で楕円の針穴があり、剣やハサミに変えない。背面の見えない部分は既存配色を最小限に延長。

turnaround：透明な2×2の等分セルに上記4姿勢を配置。針持ちは左下の針先から右上の針穴へ斜め、両手で持つ。

walk：透明な4×4の等分セル、4方向ごとに4コマの歩行。顔・耳・リボンの同一性を維持し、足の交互の運びと小さな揺れ。道具は持たず、耳や足をセル境界で切らない。最終編集で各セルの人物を約80%に縮め、約25pxの透明余白を確保。実際の出力の左右向きを検査し、ゲーム側の行番号を合わせています。

life：透明な4×4の等分セル、上記16動作。最終編集で3行目3・4列目の道具を除き、針を取る／片付ける空手の到達姿勢へ修正。各セル約25pxの余白、人物約80%へ。大針を持つ2姿勢は保持。

ゲームではアルファ領域を検出して足元を揃え、各フレームを描画します。原本PNGを切り貼りして描き直す加工はしていません。32動作フレームと確認用4姿勢を読み込み、欠損セルがないことをブラウザで検証しています。
