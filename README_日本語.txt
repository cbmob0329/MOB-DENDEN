ふたりの、ひだまり。 — 正式キャラクター素材組込・確認版
モブデンデンとモブピンクの、のんびりした3Dの部屋

【この版について】
武器を持たない正式ドット絵を、デンデン12ポーズ・ピンク12ポーズ、合計24枚組み込みました。
部屋・家具はThree.js/WebGLによる実3D、キャラクターは透過ドット絵のビルボードです。

正式画像を組み込んだ後の「ブラウザ実画面」は、まだ確認できていません。
最終的なキャラクターの表示サイズ、家具との重なり、スマホ画面の見え方は確認待ちです。
このファイルは確認可能版であり、完成版の画面検証済みという意味ではありません。
同梱のPREVIEW_CHARACTERS.jpgは実際のキャラ素材一覧で、ゲームの完成画面ではありません。

【起動】
MOB_HIDAMARI_CHECK.html を保存し、Chrome・EdgeなどWebGL対応ブラウザで開いてください。
HTML内に画像・CSS・JavaScript・Three.jsをすべて収録した、外部通信不要の単一ファイルです。
スマホではSafari/Chromeなどで開いてください。OSのファイルプレビューや一部のアプリ内プレビューではJavaScriptが実行されない場合があります。
iPhone/iPad実機Safariでの動作は未検証です。

【操作】
・ドラッグ：部屋を回転。上下へドラッグすると見下ろす高さが変わります。
・ホイール／2本指ピンチ：拡大・縮小。
・キャラ、または下の名前をタップ：10種類の行動へのお誘い。
・Ⅱ／▶：一時停止・再開。1×：1・2・4倍速。
・視点：3種類のおすすめカメラ。
・時間帯：朝・夕方・夜。
・思い出：最近60件の行動履歴。
・設定：手動保存／記録の初期化。
・音：任意ONの小さな合成音。起動時は無音。

ふたりは自分で行動を選び、家具まで歩いて向かいます。
同じ家具を相手が使っている場合は、短くお知らせします。
デンデンは休憩・おやつ・読書、ピンクは掃除・植物・音楽を好みます。
行動の詳細はACTIONS_JA.txtをご覧ください。

【保存】
思い出・行動の記録・時間帯・床上の位置を、その端末のlocalStorageに保存します。
途中の家具行動は再読み込み時に自由時間へ戻ります。
ブラウザ設定により保存できない場合も、ゲーム自体は遊べます。
キャラ画像のローカル読込は端末内のみで処理され、再読み込みすると解除されます。

【素材とソース】
source/assets/{denden,pink}/ に各12枚の256×256透過PNGがあります。
各画像は160×160の正規化素材を整数位置へ余白追加したもので、1.6倍拡大やぼかしは行っていません。
足元アンカー：画像の(128,236)。通常の立ち姿の見た目高さ：約1.4ワールド単位。
寝姿は横向き専用画像を使い、さらに回転させません。
本・カップ・布・じょうろは専用画像に含まれ、同じ3D小物の二重表示を抑えています。
source 内で node build.cjs を実行すると hidamari-standalone.html を再生成できます。
Three.js 0.160.1（MIT）のライセンスは source/vendor/THREE-LICENSE.txt です。
